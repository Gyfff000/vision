# 比赛流程与视觉职责

依据用户提供的《2027年第十届中国大学生工程实践与创新能力大赛 智能+工程创新赛道竞赛命题与运行》智能搬运部分第1至9页，重点核对第6至8页。原临时路径已失效，本次从微信msg/file/2026-09目录找到同名PDF并重新阅读全文。决赛现场规则未知，不能保证初赛程序直接适用于决赛。

二维码AAA+BBB+CCC+DDD：AAA为第一批颜色顺序，BBB为对应加工/暂存工位，CCC为第二批颜色顺序，DDD仅为第二批加工工位。第二批暂存码垛位置必须按第一批的同色关系反查。

| 阶段 | 步骤号 | 视觉 | 每步确认的实际动作 |
|---|---|---|---|
| RAW1 | 0-2 | 当前颜色的物块中心/稳定 | 第一批逐个抓取并装车 |
| PROCESS_PUT1 | 3-5 | 第一批对应工位圆环中心 | 按顺序放到粗加工区 |
| PROCESS_GET1 | 6-8 | 当前颜色的实际物块位置 | 从粗加工区重新抓取并装车 |
| STORE1 | 9-11 | 第一批对应暂存工位圆环中心 | 第一批底层放置 |
| RAW2 | 12-14 | 第二批当前颜色物块 | 第二批逐个抓取并装车 |
| PROCESS_PUT2 | 15-17 | 第二批对应加工工位 | 第二批加工区放置 |
| PROCESS_GET2 | 18-20 | 第二批当前颜色物块 | 第二批从加工区重新抓取并装车 |
| STACK2 | 21-23 | 第一批同色物块位置，STACK平面 | 同色码垛，不能照用DDD暂存 |
| RETURN_HOME | 24 | 停止抓放定位 | 主控确认回到抽签启停区 |

例156+123+516+231：第一批红/黑/浅蓝在加工及暂存1/2/3；第二批黑/红/浅蓝在加工2/3/1，暂存码垛却是2/1/3。

每个PICK_LOAD完成的含义包括：成功抓到正确物料，并放到车上。完成当前PICK_LOAD后才允许抓下一个；跨区域移动前车上载物状态必须由主控确认。每个PLACE/STACK完成的含义包括释放和到位复核，不能凭发出舵机命令就确认。确认以主控机构传感器、视觉复核和你们定义的结果共同判断。

Workflow和CompetitionController维护同一24步计划。STM32先prepare导航和调整视角，再定位，再执行动作；成功后STEP确认，重复STEP不重复计数。完成12次抓取和12次工作区放置后进入RETURN_HOME；主控回库成功再HOME_DONE，LCD显示COMPLETE及统计。统计依赖动作反馈真实性，不替代裁判评分。

转盘6-10秒/圈且会停顿。稳定标志基于连续检测中心变化，适用于停稳后抓取；不实现追踪转盘运动的预测抓取。粗加工重新抓取必须重新拍摄，不能复用放置前坐标。STACK坐标使用独立高度标定，但普通彩色连通域中心尚不是专用上表面姿态模型，需要实物/夹爪验证。

工位当前用可信ROI映射区分数字1/2/3，需要按现场/停车视角分别标定。没有自动数字OCR，也不借助赛场未允许的ArUco标记。机器需要自行识别未知布局时须增加数字识别模块，不能用固定左右排序冒充编号识别。

扫码锁定即开始第一步颜色识别和LCD实时预览，不等待STM32连接。WAIT_ACK仍定时重发任务，主控TASK_ACK后才能请求定位和推进抓放步骤；视觉预览与主控任务交接并行。
