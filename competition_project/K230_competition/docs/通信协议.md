# K230 ↔ STM32 协议

UART3 GPIO32/TX、GPIO33/RX，115200/8N1，3.3V TTL、交叉接线共地。K230 USB连接IDE的虚拟串口不是这个接口。

保留V1报文外壳，但增加完整流程命令；请使用本包配套C解析器。

```text
$V1,序号,类型,字段...*四位大写十六进制CRC\r\n
```

CRC16/CCITT-FALSE：poly=0x1021、init=0xFFFF、不反射、xorout=0；校验范围为V1至最后字段，不含$、*和换行。序号0..65535。主控请求串行执行，每次用新序号，等待DONE后读结果；CRC错误帧丢弃，超时清空结果。DONE的count只计BLOCK/RING/QR/CONTEXT数据条数，不计ACK、ERROR等控制行。max body240字节。

## 自动任务交接

有效二维码连续3次解码一致后，板端每1秒发送：

```text
V1,0,TASK,token,156+123+516+231
```

这是唯一主动事件，固定seq=0；其他结果均回答主控请求。token为32位十进制值，高16位为启动/重置会话，低16位为15字节原始任务CRC。不是加密认证码，用于关联任务与去重。C端独立校验任务四组、三种不同颜色、两批颜色相同、工位排列及token低位。

主控调用vision_ack_task发送 `TASK_ACK,token`，收到同序号 `ACK,token` 和 `DONE,0,ticks_ms` 才算确认。K230收到正确确认后自动进入COLOR。ACK丢失可重试；同任务重发不会重新抓取。主控运行中收到不同任务会停机报TASK_CHANGED，不静默改任务。

## 主控请求与应答

| 请求类型和参数 | 作用与应答 |
|---|---|
| PING | PONG,K230,2,当前模式；DONE,0,时间 |
| STATUS | CONTEXT,状态,token,步骤,阶段,目标颜色,目标工位,模式,工作平面,抓取计数,放置计数；DONE,1,时间 |
| QR | 返回已锁定任务QR,1,1,UTF8十六进制；未锁定返回NO_QR。不会强制切换赛段 |
| LOCATE，可选当前工作平面 | 对本步骤拍新图并返回目标。自动选择COLOR/RING |
| COLOR/RING，可选当前工作平面 | 与当前步骤一致才接受，否则WRONG_MODE/BAD_PROFILE |
| STEP,token,已完成步骤号 | 主控实际动作成功后确认；ACK_STEP,token,步骤号；DONE,0,时间 |
| HOME_DONE,token | 实际回库后确认；ACK,HOME_DONE；DONE,0,时间 |
| STOP | 保留任务与进度，暂停；STOPPED和DONE |
| RESUME | 从暂停前状态恢复；ACK,RESUME和DONE |
| RESET | 清除任务/步骤并回到SCAN；ACK,RESET和DONE |

工作平面RAW、PROCESS、STORE、STACK；不能请求与当前赛段不一致的标定。步骤0至23严格顺序，提前确认报STEP_MISMATCH；同token已经完成的旧步骤重发只回ACK，不重复计数。RESET只由主控在已停止机构、准备新一轮时使用；不在动作中自动RESET。

## 视觉结果

```text
V1,seq,BLOCK,id,cx,cy,dx,dy,pixels,slot,valid,stable,calibrated,x_mm,y_mm
V1,seq,RING,id,cx,cy,dx,dy,pixels,slot,valid,stable,calibrated,x_mm,y_mm
V1,seq,DONE,count,ticks_ms
```

cx/cy为640×480像素坐标，dx/dy相对config中REFERENCE_PIXEL；BLOCK id为1至6颜色，RING id/slot为工位1至3。当前仅返回本步骤目标，可能无目标。pixels已经换算为全图尺度；RING不提供面积，值为0。valid表示形状/大小/歧义过滤通过，不代表可抓取许可。stable为连续4次检测中心变化不超过配置像素范围，不是物料速度的严格测量。

calibrated=0时毫米坐标必须为NA；不能将NA当0。calibrated=1仅表示使用了已配置平面且像素在配置域内，精度仍需标定验证。frame_ms为K230拍摄后处理完成的ticks，不能直接与STM32时钟相减；主控控制器使用请求往返耗时限制结果年龄，默认最多600ms。LCD缓存框不会作为串口新结果发出。

无目标返回NO_TARGET再DONE,0；错误返回ERROR,原因再DONE,0；例如NOT_RUNNING、TASK_MISMATCH、STEP_MISMATCH、NO_SLOT_MAP、VISION_FAILED、BUSY。发生异常立即清除稳定状态和显示结果；不能继续使用上一帧位置。

## 接线测试顺序

先PING/STATUS，再扫有效任务，检查TASK原文和TASK_ACK；确认自动COLOR，移入/移出目标，检查稳定及NO_TARGET。之后分别测错误CRC、断开RX、任务重发和STEP重复，不接电机也可以做这些测试。24步模拟只用于软件验证，真实STEP必须来自实际动作反馈。
