当前硬件方向：**亚博 K230 视觉识别模块 + 一台独立 USB 摄像头**。

## 初赛视觉需要完成什么

1. 读取并校验四组三位数的任务二维码。
2. 识别红、黄、蓝、绿、黑、浅蓝物料，定位可抓取目标。
3. 判断转盘目标是否稳定，向主控提供抓取位置。
4. 识别粗加工区、暂存区的目标圆环和编号，提供放置对中偏差。
5. 重新定位粗加工区物料，辅助第二批物料在暂存区同色码垛。
6. 提供操作结果证据、异常状态和通信心跳，由主控完成流程与统计。
7. 按整车传感器分工决定是否使用视觉辅助车道定位、避障和回库。

优先跑通初赛的二维码、颜色、几何定位；决赛形状识别和装配需求按现场命题扩展。

## 当前正在做：颜色与中心检测

先运行 [k230_color_blocks.py](examples/k230_color_blocks.py) 的采样模式，用一种已知颜色填满中央小框，复制终端输出的阈值到配置区，再切换检测模式。详见[操作指南](docs/k230-color-blocks-quickstart.md)。没有实物时可打开[六色测试图](assets/color/six-color-test-card.svg)验证流程，实物到位后重新采样。当前输出是像素坐标，机械坐标标定和转盘稳定判断尚未实现。

USB相机到手后再验证USB扫码链路；比赛任务码确认仍需补测，见[进度与下一步](docs/progress.md)。
