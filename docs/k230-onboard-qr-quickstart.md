# 用 K230 自带摄像头验证扫码：从安装 IDE 开始

日期：2026-10-09。程序已做桌面语法与任务校验检查，尚未连接用户实物运行。

本阶段临时使用自带摄像头验证二维码算法。最终分工仍是“自带摄像头识别物块、USB摄像头扫码”，两路均由K230处理。

## 1. 准备和安装

准备亚博K230模块、出厂TF卡、一根支持数据传输的Type-C线和Windows电脑。先不接独立USB摄像头或主控。

打开 [亚博K230官方资料页](https://admin.yahboom.com/study/K230)，在资料汇总/配套软件下载中取得其配套的 **CanMV IDE for K230**，按“1.快速入门 / 2.安装编程环境”安装。教程展示的安装包版本为v4.0.7，实际优先使用你下载的亚博配套包；不要把其它板卡的固件当作本板固件。

已有出厂TF卡时先直接尝试连接，不为了本测试重新烧录。安装目录建议使用无中文路径，例如 `D:\CanMVIDE`。

## 2. 连接模块

1. 断电时确认TF卡插好。
2. 用数据线将模块Type-C接口连接电脑，优先使用电脑USB3.0接口。
3. 打开CanMV IDE，点击左下角连接按钮；自动连接已启用时等待连接完成。
4. 打开“串行终端”和图像“帧缓冲区”面板，分别用来观察输出和摄像头画面。
5. 若出厂GUI或其它程序正在运行，先用IDE停止按钮停止，再运行新脚本。

连接失败：先换数据线和USB口，查看设备管理器是否识别。若显示 `K230 USB Boot Device`，记录该状态并按本模块官方烧录/驱动教程排查；如果出厂GUI能正常启动，先排查连接方式，不立即重刷。

## 3. 运行准备好的程序

在电脑上用CanMV IDE打开 [扫码测试程序](../examples/k230_onboard_qr_test.py)，或者新建脚本并粘贴全部内容；点击左下角绿色运行按钮。代码发送到K230执行，不是在电脑Python中运行。

默认使用自带相机、640×480灰度图和IDE虚拟显示。模块自带实体屏幕可能不会显示该测试画面；请看IDE帧缓冲区。无需额外模型文件，也无需联网推理。

若暂时只想检查画面，将顶部 `DECODE_ENABLED = True` 改成 `False`；看到清晰画面后再改回 `True`。

首次验证先在线运行；稳定通过后再考虑保存开机程序，避免现在覆盖出厂启动脚本。

## 4. 用测试码扫码

打开 [测试二维码SVG](../assets/qr/task-156-123-516-231.svg)，内容为纯文本：

```text
156+123+516+231
```

它编码的是任务字符串本身，不是下载链接或网页地址。SVG含白色留白，标称边长80mm；要做尺寸测试时按100%打印并用尺子复核。仓库SVG可下载后用浏览器打开，也可先用本地PNG在手机/电脑屏幕显示。

把二维码完整放入镜头画面，先正对、静止，前后移动找到清楚的位置。以20-40cm作为起始尝试范围，再根据实际画面调整；这是试验起点，不是已确认识别距离。二维码周围保留白边，避免反光和过曝。

看到以下输出即可分辨三个层次：

```text
[QR] 156+123+516+231
[TASK_VALID] True
[TASK_OK] 156+123+516+231
```

- `[QR]`：二维码内容已成功解码。
- `[TASK_VALID] True`：符合本测试的初赛任务语义检查。
- `[TASK_OK]`：同一个有效任务在连续3帧中被识别，作为本次确认条件。
- `[STATUS]`：当前循环帧率、码数量和连续帧数；不是摄像头标称帧率。
- 普通网址/文字二维码仍可输出 `[QR]`，但不会当作比赛任务确认。
- 单帧无二维码或出现多个二维码时，连续确认计数重置；本测试不向主控发送动作。

## 5. 排查顺序

| 现象 | 优先处理 |
|---|---|
| IDE连不上 | 数据线、USB口、TF卡、设备管理器及配套IDE |
| 提示找不到 `media.sensor` | 确认是在CanMV IDE连接的K230上运行，记录固件版本和完整报错 |
| Sensor初始化报错 | 先跑亚博当前固件配套的摄像头显示例程；对照其Sensor参数，不猜摄像头编号 |
| Display.VIRT不支持或图像显示报错 | 记录完整错误；以本板配套例程的显示配置为准，不随意替换其它板的LCD型号 |
| 有画面但不出码 | 确认DECODE_ENABLED为True；完整白边、清晰度、大小、光照；先正对静止测试 |
| 图像似乎镜像 | 默认关闭hmirror/vflip，先保持该配置；需要调整时一次只改一项并重测 |
| 有QR但TASK_VALID为False | 检查是否扫到了网址、全角加号、空格或不合法数字；使用本仓库测试码 |
| 有QR但不出TASK_OK | 观察streak；保持静止，确保画面中只有一个码，排除间歇丢检 |
| 第二次运行相机/媒体报错 | 先点击停止；必要时复位模块、重新连接后再运行 |

不要仅因为一次扫描成功就记录为“比赛扫码通过”。先记录静态可解码，再测试80mm打印码的不同距离、偏角和光照；最后把图像输入迁移到USB摄像头，重新测试光学条件、像素格式和取帧链路。
